# AGENTS.md — pkg/

## Purpose

Varroa's public/consumable Go surface — importable by external Go programs
and `cmd/varroactl`, unlike `internal/`. Three packages: the generated
OpenAPI client, its SSE streaming helper, and the embedded pod-template
catalog.

## Ownership

- `pkg/client/` — generated + hand-written Go client for the Varroa BFF API.
- `pkg/client/stream/` — SSE client for streams the generated client excludes.
- `pkg/templates/` — in-memory `PodTemplate` catalog.

## Local Contracts

### `pkg/client`

- `gen.go` — **generated by oapi-codegen**, driven by
  `api/openapi/oapi-codegen.yaml` against `api/openapi/varroa.yaml`. Never
  hand-edit; regenerate via `make generate-client` from repo root (see
  `api/AGENTS.md`). Excludes SSE/MCP/docs operations per that config.
  Includes `listFleetPlugins` and `getFleetPlugin` (T2.2 fleet plugin inventory).
- `client.go` — hand-written wrapper, safe to edit. `client.New(baseURL,
  token, opts...)` builds a `*ClientWithResponses` with bearer-token
  injection + User-Agent `RequestEditorFn`, plus `APIError` for structured
  non-2xx decoding. `WithUserAgent` customizes the UA (e.g. `varroactl`).
  **Gotcha (client.go:15-17):** generated `GetControllerLogs` is JSON-only —
  never call with `follow=true` (response is `text/event-stream`, JSON
  decode fails). Use `pkg/client/stream` for follow-mode logs and SSE.
- `client_test.go` — tests the hand-written wrapper only.

### `pkg/client/stream`

- `stream.go` — `Stream()` (reconnecting loop, exponential backoff via
  `BackoffConfig`/`DefaultBackoff`) and `ParseSSE()` (one-shot parser).
  `Config` carries URL, bearer token, UA, `OnConnect(reconnected bool)`,
  backoff params. Used for every endpoint excluded from `gen.go` (activity,
  brood, controller events/mite, log-follow).

### `pkg/templates`

- `templates.go` — `Catalog`: thread-safe (`sync.RWMutex`), namespace-scoped
  in-memory store of `v1alpha1.PodTemplate`. `Register` validates via
  `Validate()` (≥1 container; each needs `Name`+`Image`; `RestartPolicy` ∈
  `RestartPolicyEnum` or empty) before storing. `Get`/`List` return defensive
  copies. Runtime cache, not CRD-backed (the `PodTemplate` CRD is separate,
  in `api/v1alpha1`).

## Work Guidance

- Never hand-edit `pkg/client/gen.go`; change `api/openapi/` and run `make
  generate-client` from repo root.
- New client convenience methods/auth/error-handling go in `client.go`.
- New SSE endpoints: exclude the operation ID in `oapi-codegen.yaml`, wire
  through `pkg/client/stream`, mirroring existing exclusions.
