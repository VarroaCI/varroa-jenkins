# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

Varroa is pre-1.0. Until a 1.0 release, only the latest `0.1.x` release
receives security fixes.

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities. Use
[GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability)
for this repository (Security tab → "Report a vulnerability") to open a
private advisory. Include the affected version, a description of the issue,
and reproduction steps if available.

We aim to acknowledge new reports within a few business days and to keep you
updated as a fix is developed.
